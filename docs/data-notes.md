# 数据口径与核对说明

## 快照版本

本仓库统计第1—18章，包含1,660个主线关号、1,687份关卡配置与对应地图、67座具名炮塔。官方热更核查时间为2026-11-06 18:17:50（北京时间），基础版本为1.4.0 / 37304，官方渠道更新链共36个补丁，末尾标识为 `4219b0841d`。

[官方接口核查摘要](../data/latest-update.json) 记录查询时间、补丁数量和版本一致性。[独立复核结果](../data/independent-check.json) 保存统计核对摘要及第十八章逐关文件记录。

该快照对应本次取得的官方更新链。没有直接读取玩家手机的当前 `dataVersion`，因此不将服务器资源版本与任意一台手机的当前加载状态自动等同。

## 可建造关数

设炮塔为 `t`、主题为 `c`、关号为 `l`。仅当最终生效的关卡配置 `towerlist` 包含 `t` 时，才将该关计入。

同一主题同一关号有多段配置时，先取这些配置的建造列表并集。每座炮塔在同一个关号只计一次。

```text
主题关数(t, c) = 主题c中可建造炮塔t的不重复关号数量
主线合计(t)   = 第1至18主题关数之和
主题出场率    = 主题关数 / 该主题总关数
```

第1主题40关，第2—8主题各60关，第9—18主题各120关。跨主题比较分配密度时，应使用出场率，而不是直接比较裸关数。

“可建造”不包括仅在地图上预置、仅作为奖励或仅出现在贴图预加载列表中的炮塔。281木板、1276火堆是机关，不纳入201—267的炮塔统计。

## 首次登场和零值

`firstTheme` 表示炮塔第一次出现在可建造列表中的主题。首次主题之前的零值在界面及CSV中省略；从首次主题开始，后续每个主题均保留，即使关数为0。

这项规则不代表游戏内剧情、图鉴或宣传中的第一次出现时间，只代表当前统计口径下的首次可建造主题。

## 资源取得与复核

1. 以手机导出的1.4.0 / 37304基础APK为资源起点。
2. 从游戏更新流程定位官方接口，为对应基础版本取得官方补丁链。
3. 下载并验证补丁长度、文件名MD5和ZIP CRC，按接口返回顺序覆盖资源。
4. 按实际关卡加载路径定位建造表，并逐关对应地图与波次。
5. 另一条复核流程从最后一个补丁开始向前查找实际ZIP条目，比较最终配置与地图哈希。
6. 从逐关建造列表独立汇总炮塔关号集合，比较全部67×18项主题结果、总数和首次主题。

上述源资源复核已在整理阶段完成。仓库保存统计快照及证据摘要；仓库中的 `tools/verify.py` 复核的是这些发布文件之间的一致性，不会重新下载完整补丁链。

## 第十八章核准结果

第十八章“美术馆奇妙夜”共120关。120条建造配置、120张地图和120条波次均可读取并逐关对应，最终120张地图的SHA256各不相同。

与基础安装包相比，71—120关的50条建造列表发生变化，原先49张重复的简略地图均已替换。第36个补丁没有再次改变主线炮塔建造列表。

小水母可建造关号为 **17、27、87、99、107、120**，共6关。107关为回旋镖、磁铁、小乌龟、火瓶子、小水母；120关为雷达、甜甜圈、小水母、风扇、船锚、花瓣。

建造表及波次表的最终来源补丁为 `3b481e4d60cf1e247ed93289f5367d6b`。107关地图来自 `58a59ae4e4f18881e5cbd03bcc6af762`，120关地图来自 `9986bb003b061db0e893722d2d40f731`。

[第十八章逐关CSV](../data/chapter18-levels.csv) 提供每关建造列表、波次数、地图大小、对象数、SHA256及来源补丁。

第十九章存在大量相同简略占位地图，未纳入本仓库主线关数；没有将占位配置当作完整实装出场。

## JSON主要字段

### `mainline.json`

| 字段 | 含义 |
| --- | --- |
| `themes` | 主题编号、名称、总关数、配置份数 |
| `towers` | 炮塔ID、名称、主线合计、各主题关数与关号 |
| `towers[].counts` | 18项数组，下标0对应第1主题 |
| `towers[].levels` | 18项数组，每项保存该主题可建造关号 |
| `towers[].firstTheme` | 首次可建造主题编号，从1开始 |
| `levels` | 1,660个主线关号，包含去重后的炮塔ID和证据索引 |
| `evidence` | 1,687份配置记录，含原始建造列表、地图哈希与资源来源 |
| `observations` | 整理时保留的真机观察记录，不在官方表之外重复加算 |
| `audit` | 统计范围、排除项、资源版本与复核摘要 |

### 逐关证据字段

| 字段 | 含义 |
| --- | --- |
| `theme` / `level` / `key` | 主题、关号及配置key |
| `rawTowerlist` | 最终生效配置中的完整原始建造ID列表 |
| `configTowerIds` / `towerIds` | 排除机关后的具名可建造炮塔ID |
| `rawConfig` | 完整关卡配置 |
| `textureOnly` / `presetOnly` / `rewardOnly` | 仅贴图、预置或奖励中的ID，不自动计作可建造 |
| `mapSha256` | 解密后地图字节的SHA256 |
| `configSource` / `mapSource` / `waveSource` | 最终资源来自基础包还是哪个补丁 |
| `rawMapXml` | 第十八章地图XML原文 |

部分 `config`、`map`、`source` 字段保留原始分析工程中的相对路径，作为来源记录；这些路径不表示仓库中存在完整游戏工程。

## 图标映射

`icon-mapping.json` 保存67座炮塔的名称、ID、资源名、PNG SHA256，以及32/64位模块中的映射证据。仓库内实际PNG位于 `assets/towers/<ID>.png`。

- 204导弹塔：`AirBottle`。
- 258飞弹：`Missile`，绿色弹头。
- 262三连塔：`Like`。

`tools/verify.py` 会逐张比较PNG哈希，防止后续修改页面时再次错配。

## 构建和浏览器验证

`tools/build.py` 将模板、核对数据、更新摘要和67张PNG合成为 `index.html`。`tools/verify.py` 检查关号集合、主题计数、总计、CSV零值规则、图标哈希、文档本地链接，并验证页面可由仓库文件原样重建。

`tools/capture.py` 打开真实离线页面，检查列表、矩阵、关号追溯、零值主题、CSV导出与手机布局，同时生成README截图。浏览器验证摘要见 [browser-check.json](../data/browser-check.json)。
